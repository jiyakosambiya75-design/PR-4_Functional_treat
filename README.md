# 🚀📊 Data Analyzer & Transformer ✨🐍

> ### 💡 *"Turning Raw Data into Smart Insights with Python."* 📈

---

## 🌸 Welcome!

Hello! 👋

Welcome to **Data Analyzer & Transformer**, a Python-based menu-driven application built to make data analysis simple, interactive, and enjoyable.

Data is everywhere, but understanding it is what truly matters. This project helps users perform common data operations such as analyzing datasets, sorting values, filtering information, calculating statistics, and much more—all through a clean and user-friendly console interface.

Rather than creating multiple small programs, I combined different Python concepts into one practical application that demonstrates both programming fundamentals and logical problem-solving.

---

## ✨ Why This Project?

Every developer begins with a single project, and this is one of the milestones in my Python journey. 🚀

The goal of this project was not only to practice Python syntax but also to understand how different concepts work together to build a complete application.

While working on this project, I explored data manipulation, function design, program structure, and logical thinking. Every feature taught me something new and made me more confident as a programmer.

---

## 🌟 Key Features

📥 Accepts both **1D** and **2D** array input

📊 Generates quick dataset summaries

🔍 Filters data using user-defined threshold values

📈 Sorts data in both ascending and descending order

🧮 Calculates factorial values

📋 Displays useful statistical information

⚡ Interactive and beginner-friendly menu system
